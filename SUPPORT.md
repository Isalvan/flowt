## Abrir una consulta

Utiliza la plantilla de bug cuando el comportamiento observado difiera del esperado. Incluye:

- versión o commit;
- entorno y navegador o versión de Python;
- pasos de reproducción;
- resultado esperado y resultado obtenido;
- logs depurados;
- capturas cuando sean útiles.

Elimina credenciales, correos, UID, movimientos y datos financieros antes de adjuntar información.

## Solicitudes de funcionalidad

Utiliza la plantilla de propuesta y describe el problema de usuario, el comportamiento deseado y alternativas consideradas.

## Seguridad

Las vulnerabilidades no deben comunicarse mediante issues públicos. Sigue [SECURITY.md](SECURITY.md).

## Alcance del soporte

El mantenimiento se realiza con disponibilidad limitada y no se ofrece un plazo garantizado de respuesta. Las solicitudes reproducibles, acotadas y acompañadas de contexto pueden atenderse con mayor facilidad.
